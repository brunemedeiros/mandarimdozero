## 2. Como foi feito

- Catálogos carregados em Node (`vm`) e cada valor conferido por expressão regular ("--", "pra/pro/pras/pros" como palavra
  inteira, letra seguida de "(s)", "(ões)", "(es)", "/a", "(a)", lista de termos técnicos, lista de palavras de culpa). Chaves
  de admin e professora separadas pelo prefixo (`admin.`, `adminChallenges.`, `panel.`, `rb.`, `badges.`, `teacherMaterials.`).
  Falsos positivos tirados à mão: "Premium Pro", "Note" com sentido de "observação" no inglês (`myClassLogs.observations`,
  `mural.sub`, `publicProfile.labelNote`) e "lá/aí" numa explicação de francês.
- Literais de string do JS (sem comentários) de `fr/app.js`, `zh/app.js`, `shared/**/*.js` e das Edge Functions; nós de texto e
  atributos do HTML (sem `<script>`, `<style>` e comentários) e os scripts embutidos.
- Plurais montados à mão: chaves com `{n}` + substantivo sem `.one`, e trechos `=== 1 ? '...' : '...'` no código. Conferido
  onde cada chave de risco é usada (por exemplo, metas de conquista já têm chave própria para o nível 1).
- Banco: `notification_templates` inteiro, `notification_rules` e o código atual (`pg_proc`) das funções que gravam em
  `notifications` ou montam frase. Contagem real dos avisos com "1 dias"/"1 missões" em `notifications`.
- Proposta automática só para troca mecânica ("--" vira ponto ou dois-pontos; "pra" vira "para"); o resto foi escrito à mão.
  Confiança das traduções novas para o inglês: alta, salvo onde marcado.
