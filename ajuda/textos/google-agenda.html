Resumo: o site só lê as agendas que a professora escolher, para registrar as aulas com o dia e o horário certos. Ele nunca cria, muda nem apaga nada no Google Agenda, não vende nem repassa os dados e não usa esses dados para anúncios.

Quem usa e para quê

A conexão com o Google Agenda é opcional e serve só para professoras do site Idiomas com Prof. Brune (app.profbrune.com.br). Quando uma professora conecta a conta, o site lê os eventos das agendas que ela marcar e, para cada aula reconhecida, cria ou atualiza o registro da aula do aluno (dia, horário e duração). Os alunos não conectam nada.

O que o site pede ao Google

  • Ver os eventos das suas agendas (permissão só de leitura, calendar.readonly).
  • Seu endereço de e-mail do Google, para mostrar qual conta está conectada.

O site não pede permissão para escrever na sua agenda, ler seus e-mails, contatos ou arquivos.

O que fica guardado

  • O e-mail da conta Google conectada e uma chave de acesso (fornecida pelo Google) que permite ao site ler a agenda de tempos em tempos. Essa chave fica só no servidor; nem o navegador nem outras pessoas têm acesso a ela.
  • O nome de cada agenda da conta e a escolha da professora (ler ou não ler cada uma).
  • Dos eventos das agendas marcadas, de maio de 2025 até 90 dias à frente: título, início, fim, fuso horário, se foi cancelado e os convidados (nome e e-mail), usados para reconhecer de qual aluno é a aula.
  • Eventos que não são aula (por exemplo, compromissos pessoais ou de dia inteiro): o site guarda só que existem e que não são aula; o título e os convidados são apagados assim que o site decide que não é aula.
  • As escolhas que a professora ensina ao site (por exemplo, "eventos com o título X são do aluno Y").

Quem vê esses dados

  • A professora vê as próprias aulas e os eventos que o site não reconheceu, para decidir de quem é a aula.
  • Cada aluno vê só as próprias aulas (data, horário, tema, tarefa e presença), como já acontece no site. Os alunos não veem a agenda da professora nem os outros eventos dela.
  • Os dados ficam no banco de dados do site (Supabase), protegidos por regras de acesso e transmitidos com criptografia (HTTPS). Não são vendidos, não são repassados a terceiros e não são usados para publicidade nem para treinar inteligência artificial.

Uso limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como desconectar e apagar

  • No site: Professora > Aulas > Calendário > Google Agenda > Desconectar. Isso apaga a chave de acesso, a lista de agendas e os eventos guardados. As aulas já registradas continuam no site, porque fazem parte do histórico das aulas; a professora pode apagá-las quando quiser.
  • No Google: em myaccount.google.com/permissions, remova o acesso de "Idiomas com Prof. Brune". A partir daí o site não consegue mais ler a agenda.
  • Para apagar também as escolhas que você ensinou ao site, ou para qualquer dúvida, escreva para contato@profbrune.com.br.

Mudanças

Se esta página mudar, a data no topo é atualizada. Mudanças no que é lido ou guardado são avisadas no site antes de valer.
